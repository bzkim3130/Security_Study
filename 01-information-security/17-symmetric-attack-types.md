# 대칭키 암호 공격 유형 (COA / KPA / CPA / CCA)

## 한줄 요약
> 공격자가 가진 정보가 많을수록 공격이 강력해지며, 순서는 COA(암호문만) < KPA(평문-암호문 쌍을 얻음) < CPA(평문을 골라 암호화시킴) < CCA(암호문을 골라 복호화시킴)이다.

## 1. 4가지 공격 유형 비교

| 공격 | 영문 풀네임 | 공격자가 가진 정보 |
|---|---|---|
| COA (암호문 단독 공격) | Ciphertext Only Attack | 암호문만 확보 |
| KPA (기지 평문 공격) | Known Plaintext Attack | 일부 **평문-암호문 쌍**(같은 키로 생성된) 확보 |
| CPA (선택 평문 공격) | Chosen Plaintext Attack | 원하는 **평문을 골라 암호화**시켜볼 수 있음 |
| CCA (선택 암호문 공격) | Chosen Ciphertext Attack | 원하는 **암호문을 골라 복호화**시켜볼 수 있음 |

## 2. 공격 강도 진행 순서

```
COA(가장 약함) → KPA → CPA → CCA(가장 강함)
암호문만 있음   평문-암호문 쌍 있음   평문 선택 가능   암호문 선택 가능(복호화 오라클)
```

## 3. 핵심 함정: KPA의 정의

**틀린 이해**: "그냥 아무 평문이나 알고 있으면 KPA"
**정확한 정의**: KPA는 **같은 키로 암호화된 평문-암호문 쌍**을 확보하고 있어야 성립 — 단순히 "평문 내용을 안다"는 것만으로는 부족, 그 평문에 대응하는 암호문까지 확보해야 함

## 암기 팁
- **강도 순서 "코크초코"**: **CO**A → **K**PA → **C**PA → **C**CA (약한 순서대로)
- **"C가 붙으면 내가 고른다(Chosen)"** — CPA/CCA는 공격자가 능동적으로 평문/암호문을 골라 시스템에 넣어볼 수 있음
- **"P는 평문을 넣고, C는 암호문을 넣는다"** — CPA(Plaintext 선택), CCA(Ciphertext 선택)

## 헷갈리는 포인트
- KPA는 "평문을 안다"가 아니라 **"같은 키로 만들어진 평문-암호문 쌍을 갖고 있다"**는 것이 정확한 정의 — 시험 함정 포인트
- CPA와 CCA 둘 다 "오라클(질의 가능한 블랙박스)"을 이용하는 능동적 공격이라는 공통점 — 차이는 무엇을 입력하느냐(평문 vs 암호문)

## 관련 기출/문제
- 4가지 공격의 강도 순서 나열
- KPA의 정확한 정의(단순 평문 인지 vs 평문-암호문 쌍)
- CPA/CCA에서 "선택"의 의미
