# 사이버위기경보 5단계

## 한줄 요약
> 국가사이버안전관리규정 제11조에 따라 정상-관심-주의-경계-심각 5단계로 나뉘며, 실제로는 "경계"와 "심각"이 발령된 적이 거의 없다.

## 1. 5단계 등급표

| 단계 | 색상 | 상황 |
|---|---|---|
| 정상 | (기본) | 위협 없음, 평상시 |
| 관심 | 파랑 | 위협 정보 있으나 실제 피해 없음, 예방적 모니터링 |
| 주의 | 노랑 | 침해사고 발생 가능성 증가, 일부 피해 발생 |
| 경계 | 주황 | 다수 기관 대상 광범위 피해 발생/우려 |
| 심각 | 빨강 | 국가적 차원의 심각한 피해, 전면적 위기대응체계 가동 |

## 2. 흐름도

```
정상 → 관심(파랑) → 주의(노랑) → 경계(주황) → 심각(빨강)
        예방 모니터링   일부피해     광범위피해     국가위기
```

## 3. 주관 기관

- **국가정보원 산하 국가사이버안전센터(NCSC)**가 관리·발령

## 암기 팁
- **"정관주경심"** 5단계 순서 암기
- 색상 순서: **파랑(관심)→노랑(주의)→주황(경계)→빨강(심각)** — 신호등보다 한 단계 더 있다고 생각
- **"경계·심각은 실제로 거의 발령 안 됨"** — 시험 함정: "역대 발령 최고 단계는?"류 문제에서 주의로 답하는 경우가 많음

## 헷갈리는 포인트
- 이 5단계 체계는 **재난문자용 4단계 국민재난안전 경보(관심-주의-경계-심각)**와는 다른 체계 — 사이버위기경보는 별도의 5단계(정상 포함)

## 관련 기출/문제
- 5단계 순서와 색상 매칭
- 관리 기관 (국가정보원/NCSC)
- "경계", "심각" 단계 실제 발령 이력
