# 패스워드 크래킹 공격 기법

## 한줄 요약
> 무작위대입(Brute Force)은 모든 조합, 사전공격(Dictionary)은 흔한 단어 목록, 레인보우테이블(Rainbow Table)은 미리 계산된 해시-평문 매핑을 쓰며, 차분암호분석(Differential Cryptanalysis)은 패스워드 공격이 아니라 블록암호 자체를 분석하는 별개 기법이다.

## 1. 주요 공격 기법 비교

| 기법 | 원리 | 특징 |
|---|---|---|
| 무작위 대입(Brute Force) | 가능한 모든 조합을 순차 시도 | 시간 오래 걸림, 이론상 항상 성공 |
| 사전 공격(Dictionary Attack) | 흔히 쓰이는 단어/패턴 목록으로 시도 | 빠르지만 목록에 없으면 실패 |
| 레인보우 테이블(Rainbow Table) | 해시값-평문 매핑을 미리 계산해둔 테이블 조회 | 매우 빠름, 저장공간 필요, **Salt로 무력화 가능** |
| 하이브리드 공격 | 사전공격 + 규칙기반 변형(숫자/특수문자 추가 등) | 사전공격보다 커버리지 넓음 |

## 2. 레인보우 테이블 vs Salt

```
Salt 없이: 해시(패스워드) → 레인보우테이블에서 즉시 조회 가능
Salt 사용: 해시(패스워드+Salt) → 같은 패스워드도 Salt마다 다른 해시 → 테이블 무력화
```

## 3. 함정: 차분 암호분석(Differential Cryptanalysis)은 패스워드 공격이 아님

**차분 암호분석**은 **블록암호(예: DES) 자체의 구조적 취약점**을 분석하는 암호해독 기법으로, 평문 쌍의 차이(XOR)가 암호문 쌍의 차이에 미치는 영향을 통계적으로 분석 — **패스워드를 직접 크래킹하는 기법이 아니라 암호 알고리즘 분석 기법**

| 구분 | 대상 |
|---|---|
| Brute Force / Dictionary / Rainbow Table | 패스워드(해시) 자체를 깨는 공격 |
| 차분 암호분석(Differential Cryptanalysis) | 블록암호 **알고리즘 구조**를 분석하는 암호학적 공격 |

## 암기 팁
- **"무작위=다 해봄, 사전=흔한 것부터, 레인보우=미리 계산해둔 치트키"**
- **"차분암호분석은 패스워드 아니고 알고리즘 공격"** — 보기에 섞여 나오면 이것만 골라내면 정답
- **레인보우테이블의 천적 = Salt**

## 헷갈리는 포인트
- 시험에서 "패스워드 크래킹 기법이 아닌 것은?" 유형에 **차분 암호분석**이 함정으로 자주 등장 — 이름이 "암호분석"이라 헷갈리지만 대상이 다름
- 레인보우테이블은 Brute Force보다 빠르지만 **사전에 대용량 테이블을 계산·저장**해둬야 해서 준비 비용이 큼

## 관련 기출/문제
- "다음 중 패스워드 크래킹 기법이 아닌 것은?" → 차분 암호분석
- Rainbow Table을 무력화하는 방법(Salt)
- Brute Force vs Dictionary Attack 차이
