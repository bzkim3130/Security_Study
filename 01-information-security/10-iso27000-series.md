# ISO/IEC 27000 시리즈 (27001 vs 27002)

## 한줄 요약
> 27001은 "인증받는 요구사항(shall)" 표준, 27002는 "실무 구현 가이드(should)" 표준이며, 둘 다 BS7799에서 출발했다.

## 1. 계보

```
BS7799 Part 1 (실무 가이드) ──▶ ISO/IEC 17799 ──▶ ISO/IEC 27002 (실무 지침)
BS7799 Part 2 (인증 요구사항) ────────────────────▶ ISO/IEC 27001 (인증 표준)
```

## 2. 핵심 비교

| 구분 | ISO/IEC 27001 | ISO/IEC 27002 |
|---|---|---|
| 성격 | 요구사항(인증 가능) | 실무 구현 가이드(인증 불가) |
| 언어 | "shall"(해야 한다, 강제) | "should"(권고) |
| 용도 | 인증기관 심사 기준 | 27001의 통제항목을 실제로 어떻게 구현할지 안내 |
| 핵심 개념 | ISMS(정보보안관리체계) 구축·인증 | 세부 통제 구현 방법론 |

## 3. 27000 시리즈 주요 표준

| 표준 | 내용 |
|---|---|
| 27000 | 용어 및 개요 |
| 27001 | ISMS 요구사항 (인증표준) |
| 27002 | 실무 지침(통제 구현 가이드) |
| 27005 | 정보보안 위험관리 |
| 27017 | 클라우드 보안 통제 |
| 27018 | 클라우드 개인정보보호 |

## 암기 팁
- **"1은 인증(자격증처럼 심사받는 것), 2는 매뉴얼(어떻게 할지 설명서)"**
- **"shall=강제(27001), should=권고(27002)"**
- 계보: "BS7799가 할아버지, 그중 Part2가 27001(인증)로, Part1이 27002(가이드)로 갈라짐"

## 헷갈리는 포인트
- 27002는 그 자체로 인증받는 표준이 아님 — 27001 인증 심사할 때 "어떻게 구현했는지" 참고자료로 쓰임
- 27001의 Annex A 통제목록과 27002의 목차는 번호가 대응됨 (예: 27001의 A.9 접근통제 ↔ 27002의 9장)

## 관련 기출/문제
- 27001 vs 27002 성격 구분 (인증가능 여부)
- BS7799 Part1/Part2가 각각 어느 ISO 표준으로 이어졌는지
