# 비식별화 기술 (개인정보 비식별화)

## 한줄 요약
> 비식별화는 가명처리·총계처리·삭제·범주화·마스킹·암호화 6대 기법으로 이루어지며, 암호학적으로는 일방향해시(+Salt)/순서보존암호화(OPE)/형태보존암호화(FPE)/동형암호/차분프라이버시가 핵심 도구다.

## 1. 비식별화 6대 기법

| 기법 | 원리 | 예시 |
|---|---|---|
| 가명처리(Pseudonymization) | 식별자를 다른 값으로 대체 | 홍길동→고객A |
| 총계처리(Aggregation) | 개별값 대신 통계값(합계/평균)만 제공 | 개인소득→평균소득 |
| 삭제(Suppression) | 식별 가능 항목 자체를 제거 | 주민번호 뒷자리 삭제 |
| 범주화(Generalization) | 구체값을 범위/구간으로 뭉뚱그림 | 27세→20대 |
| 마스킹(Masking) | 일부를 특수문자로 가림 | 홍길동→홍** |
| 암호화(Encryption) | 알고리즘으로 값 자체를 변환 | AES 등으로 암호화 저장 |

## 2. 암호학적 비식별화 기법 상세

| 기법 | 원리 | 특징 |
|---|---|---|
| 일방향 해시함수 + Salt | 해시(값+Salt) | 복호화 불가능(비가역), Salt로 레인보우테이블 방어 |
| OPE (Order-Preserving Encryption, 순서보존암호화) | 암호화해도 **크기 순서가 유지**됨 | 암호문 상태로 범위검색(>,< 등) 가능 |
| FPE (Format-Preserving Encryption, 형태보존암호화) | 암호화해도 **원래 형식(자릿수/문자종류) 유지** | 카드번호→같은 16자리 숫자형태로 암호화 |
| 동형암호(Homomorphic Encryption) | 암호문 상태로 **연산까지 가능**, 복호화한 결과와 동일 | 데이터를 안 풀고도 연산(클라우드 위탁연산 등)에 활용 |
| 차분 프라이버시(Differential Privacy) | 통계 결과에 **노이즈를 추가**해 개인 식별 불가능하게 | 통계 조회 결과만 노출, 원본은 안전 |
| 다형성암호화(Polymorphic Encryption) | 같은 평문도 암호화할 때마다 **다른 암호문** 생성 | 패턴 분석/연결공격(Linkage) 방지 |

## 3. 도식화

```
개인정보 비식별화
├── 일반 기법 (가총삭범마암)
│    가명처리-총계처리-삭제-범주화-마스킹-암호화
│
└── 암호학적 기법 (해동차포)
     해시(+Salt)-동형암호-차분프라이버시-포맷유지(OPE/FPE)
```

## 4. 가명정보 vs 익명정보 (개인정보보호법 관점)

| 구분 | 가명정보(Pseudonymous) | 익명정보(Anonymous) |
|---|---|---|
| 재식별 가능성 | 추가정보 결합 시 **재식별 가능** | 재식별 **불가능**(완전 비식별) |
| 법적 지위 | 개인정보보호법 적용 대상(추가 규제) | 개인정보 아님(법 적용 제외) |
| 활용 | 통계작성·연구·공익적기록보존 목적 별도 동의없이 활용가능 | 자유롭게 활용 가능 |

## 암기 팁
- **일반 6대 기법 "가총삭범마암"**: 가명처리-총계처리-삭제-범주화-마스킹-암호화
- **암호학적 기법 "해동차포"**: 해시-동형암호-차분프라이버시-포맷유지(OPE/FPE)
- **"OPE는 순서, FPE는 형태"** — Order(순서) vs Format(형태), 이름 그대로 암기
- **"동형암호 = 잠근 채로 계산 가능한 금고"**

## 헷갈리는 포인트
- 가명처리와 익명처리를 혼동하기 쉬움 — 가명정보는 **재식별 가능**(개인정보보호법 적용 O), 익명정보는 **재식별 불가능**(법 적용 X)
- 동형암호는 일반 암호화와 달리 **복호화 없이 암호문 상태로 연산 가능**하다는 게 핵심 차별점 — "그냥 강력한 암호화"로 오해하지 않기
- OPE는 순서 정보가 암호문에도 남아있어서 **일반 암호화보다 보안성이 낮음**(패턴 추론 가능성) — 검색 편의성과 보안성의 트레이드오프

## 관련 기출/문제
- 6대 비식별화 기법 매칭
- 가명정보 vs 익명정보 법적 지위 차이
- OPE vs FPE 차이(순서보존 vs 형태보존)
- 동형암호의 특징(복호화 없이 연산 가능)
