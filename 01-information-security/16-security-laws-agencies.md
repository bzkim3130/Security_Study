# 정보보호 법률과 소관 행정기관

## 한줄 요약
> 개인정보보호법은 개인정보보호위원회, 정보통신망법은 과기정통부/방통위, 정보통신기반보호법은 국정원(조정)+개별 관계기관(관리)이 소관하며, 2020년 데이터 3법 개정으로 개인정보 관련 조항이 망법에서 개인정보보호법으로 이관됐다.

## 1. 법률-소관기관 매핑

| 법률 | 소관 기관 | 핵심 대상 |
|---|---|---|
| 개인정보보호법 | 개인정보보호위원회 | 모든 개인정보처리자(공공+민간) |
| 정보통신망법 | 과학기술정보통신부 / 방송통신위원회 | 정보통신서비스 제공자 |
| 정보통신기반보호법 | 국가정보원(조정) + 관계 중앙행정기관(개별 관리) | 주요정보통신기반시설 |
| 전자금융거래법 | 금융위원회 | 금융회사, 전자금융업자 |

## 2. 계층 구조

```
정보보호 법률 체계
├── 개인정보보호법 ── 개인정보보호위원회 (2020년 이후 통합 컨트롤타워)
├── 정보통신망법 ── 과기정통부/방통위
├── 정보통신기반보호법 ── 국정원(조정) + 개별 관계기관(관리)
└── 전자금융거래법 ── 금융위원회
```

## 3. 2020년 데이터 3법 개정 핵심

**개정 전**: 개인정보 관련 조항이 개인정보보호법, 정보통신망법, 신용정보법에 흩어져 있어 중복규제 문제

**개정 후**: 정보통신망법의 개인정보 관련 조항을 **개인정보보호법으로 이관**, 개인정보보호위원회가 통합 감독기구로 격상

```
개정 전: 정보통신망법 안에 개인정보 조항 존재(온라인 사업자 대상 개별 규율)
              │
              ▼  (2020 데이터3법)
개정 후: 개인정보 조항 → 개인정보보호법으로 통합 이관
        정보통신망법에는 순수 "정보통신망" 관련 조항만 남음
```

## 4. ISMS-P 인증 운영 구조

- **ISMS-P(정보보호 및 개인정보보호 관리체계 인증)**: 과기정통부(정보통신망법)와 개인정보보호위원회(개인정보보호법)가 공동 운영
- 실무 운영은 **KISA(한국인터넷진흥원)**가 담당

## 5. 정보통신기반보호법의 이중 구조

- **국가정보원**: 전체 취약점 분석·평가 기준 마련, 조정 역할
- **개별 관계 중앙행정기관**: 소관 분야 주요정보통신기반시설을 직접 지정·관리 (예: 금융분야는 금융위, 통신분야는 과기정통부)

## 암기 팁
- **"개통금위국"**: **개**인정보보호위(개인정보법) - 과기정**통**부/방통위(망법) - **금**융위(전자금융법) - 국정원(기반보호법, 조정 역할)
- **"2020년 데이터3법 = 개인정보 조항 대이동"** — 망법에서 개인정보법으로 이사
- **정보통신기반보호법 = "국정원은 코치, 개별기관이 선수"** — 국정원은 조정만, 실제 관리는 각 기관

## 헷갈리는 포인트
- 정보통신기반보호법은 국정원이 "전부 관리"하는 게 아니라 **조정 역할**이고, 실제 지정·관리는 **개별 관계기관**이 함 — 착각하기 쉬움
- ISMS-P는 단일 기관이 아니라 **과기정통부+개인정보위 공동 운영**, KISA는 실무 대행 기관
- 2020년 개정으로 "개인정보보호법이 새로 생긴 것"이 아니라, 기존 법의 **조항 이관+통합**이 이루어진 것

## 관련 기출/문제
- 법률별 소관 기관 매칭
- 2020년 데이터3법 개정으로 이관된 내용
- ISMS-P 운영 주체(공동운영+KISA 실무) 구분
- 정보통신기반보호법에서 국정원의 역할(조정) vs 개별기관의 역할(관리)
