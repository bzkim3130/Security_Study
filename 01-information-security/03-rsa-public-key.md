# RSA 공개키 암호

## 한줄 요약
> 두 소수의 곱(n)과 오일러 피함수(φ(n))를 이용해 공개키/개인키를 만들고, 모듈러 거듭제곱으로 암복호화한다.

## 1. 키 생성 (Key Generation)

**소수 선택**: 두 개의 큰 소수 p, q 선택

**모듈러스 계산**
$$n = p \times q$$

**오일러 피함수 (토션트)**
$$\phi(n) = (p-1)(q-1)$$

**공개키 지수 e 선택**
$$1 < e < \phi(n), \quad \gcd(e, \phi(n)) = 1$$
(보통 e = 65537 많이 사용)

**개인키 지수 d 계산** (e의 모듈러 역원, 확장 유클리드 호제법으로 계산)
$$e \times d \equiv 1 \pmod{\phi(n)}$$

**결과**
- 공개키: (n, e)
- 개인키: (n, d)

## 2. 암호화 / 복호화

**암호화**: 평문 M (단, M < n)
$$C = M^e \bmod N$$

**복호화**
$$M = C^d \bmod N$$

## 3. 수학적 원리

$$C^d \bmod n = (M^e)^d \bmod n = M^{ed} \bmod n$$

$ed \equiv 1 \pmod{\phi(n)}$ 이므로 오일러 정리에 의해 $M^{ed} \bmod n = M \bmod n$

## 4. 간단 예시

- p=3, q=11 → n=33, φ(n)=20
- e=3 (gcd(3,20)=1) → d=7 (3×7=21≡1 mod 20)
- M=4 → C = 4³ mod 33 = 64 mod 33 = **31**
- 복호화: M = 31⁷ mod 33 = **4** ✓

## 5. 모듈러 거듭제곱 빠르게 계산하는 법 (손계산 트릭)

**핵심 공식**
```
(A × B) mod N = ((A mod N) × (B mod N)) mod N
```
→ 곱하기 전에 미리 mod를 씌워서 숫자를 작게 만들어도 결과는 같다.

**예시: 6¹² mod 13**

```
   6
   │ 제곱 (²)
   ▼
  36 mod 13 = 10
   │ 제곱 (²)
   ▼
 100 mod 13 = 9
   │ 세제곱 (³)  ← 10이 6개였으니 9는 3개
   ▼
 729 mod 13 = 1   ★ 정답
```

풀이 순서: 6¹² = 6^(2×2×3) → **"제곱 → mod → 제곱 → mod"** 반복하며 숫자를 작게 유지 → 이게 실제 RSA/DH에서 쓰는 "빠른 거듭제곱법(Square-and-Multiply)"의 손계산 버전.

## 실무 계산 팁

| 항목 | 방법 |
|---|---|
| 빠른 거듭제곱 | 모듈러 거듭제곱 (Square-and-Multiply) |
| d 계산 | 확장 유클리드 호제법 |
| 큰 수 소수 판별 | 밀러-라빈 소수판별법 |

## 암기 팁
- 최소 암기: **e × d ≡ 1 mod φ(n)** / **C = Mᵉ mod N** / **M = Cᵈ mod N**
- "곱하기 전에 mod 먼저 씌워도 답은 같다" — 큰 지수 계산의 전부

## 헷갈리는 포인트
- φ(n)은 (p-1)(q-1)이지 n-1이 아님 (p, q가 소수이기 때문)
- e와 d는 서로 역원 관계이지, 아무 숫자나 골라도 되는 게 아님 (gcd(e, φ(n))=1 조건 필수)

## 관련 기출/문제
- p, q, e 주어지고 d 구하기 / C, M 계산하기 유형
- 6¹² mod 13 같은 모듈러 거듭제곱 손계산 문제
