# 타원곡선 암호(ECC) 스칼라 배 (기하학적 구성)

## 한줄 요약
> 점 P를 k번 더한 kP는 "배가(Doubling, 접선)"와 "덧셈(Addition, 두 점을 잇는 직선)"을 반복해서 계산하며, 매번 곡선과의 교점을 x축 기준으로 대칭이동(반사)해야 진짜 결과가 나온다.

## 1. 기본 연산 2종류

| 연산 | 방법 | 언제 사용 |
|---|---|---|
| 배가(Doubling) | 점 P에서 **접선**을 그어 곡선과 만나는 세 번째 점을 구하고, x축 대칭 | 2P, 4P, 8P처럼 같은 점을 두 배로 늘릴 때 |
| 덧셈(Addition) | 서로 다른 두 점 P, Q를 잇는 **직선**을 그어 곡선과 만나는 세 번째 점을 구하고, x축 대칭 | P+Q처럼 다른 두 점을 더할 때 |

## 2. 기하학적 절차 (스칼라 배 kP 구하기)

```
1단계: P에서 접선을 그어 곡선과의 세 번째 교점을 찾음
2단계: 그 교점을 x축 기준으로 반사(reflect) → 이게 진짜 2P
3단계: 2P와 P를 잇는 직선을 그어 곡선과의 세 번째 교점을 찾음
4단계: 그 교점을 x축 기준으로 반사 → 이게 3P
   ... (반복)
```

```
      곡선
       │
   P ●─┼─(접선)── 교점(반사 전)
       │              │
       │           x축 대칭
       │              ▼
       │           2P ● (진짜 결과)
```

## 3. 핵심 포인트: "반사"를 빼먹으면 안 됨

곡선과 직선/접선의 교점 자체는 **-2P(또는 -(P+Q))**에 해당 — 이걸 x축 기준으로 뒤집어야(y좌표 부호 반전) 진짜 원하는 **2P(또는 P+Q)**가 나옴

## 4. 유한체(모듈러 연산)로의 전환

실제 암호에서는 기하학적 그림 대신 **유한체 위의 모듈러 연산**으로 계산 (컴퓨터로 처리 가능하게):
- 배가/덧셈 공식을 대수식(모듈러 나눗셈 포함)으로 표현
- 원리(교점 찾기+반사)는 동일하지만 실제 계산은 mod p 연산으로 수행

## 암기 팁
- **"접선=배가(Double), 직선=덧셈(Add)"**
- **"교점 찾고 뒤집기"** 2단계를 항상 세트로 기억 — 반사 빼먹으면 오답
- 기하학적 방법은 "이해용", 실제 계산은 "모듈러 연산" — 시험에서 개념(기하학)과 실전계산(모듈러)을 구분해서 물어볼 수 있음

## 헷갈리는 포인트
- 교점을 찾는 것 자체로 끝났다고 착각하기 쉬움 — **반드시 x축 대칭(반사)까지 해야** 올바른 kP가 나옴
- 배가(Doubling)와 덧셈(Addition)을 헷갈리기 쉬움 — 같은 점끼리는 접선(배가), 다른 점끼리는 직선(덧셈)

## 관련 기출/문제
- 그림에서 접선/직선 그은 횟수로 k값(kP=?) 추론하는 문제
- 배가와 덧셈의 기하학적 차이 구분
- 교점을 x축 대칭시켜야 하는 이유
