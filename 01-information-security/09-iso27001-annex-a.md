# ISO 27001 Annex A 14개 통제 영역

## 한줄 요약
> Annex A는 "무엇을 통제할지"의 실행 항목 14개 영역이고, 본문 조항(Clause 4~10, PDCA)은 "관리 시스템 운영 방법"이라 서로 층위가 다르다.

## 1. Annex A 14개 영역 (A.5~A.18)

| 번호 | 한글명 | 영문명 |
|---|---|---|
| A.5 | 정보보안 정책 | Information Security Policies |
| A.6 | 정보보안 조직 | Organization of Information Security |
| A.7 | 인적 자원 보안 | Human Resource Security |
| A.8 | 자산 관리 | Asset Management |
| A.9 | 접근통제 | Access Control |
| A.10 | 암호화 | Cryptography |
| A.11 | 물리적/환경적 보안 | Physical and Environmental Security |
| A.12 | 운영 보안 | Operations Security |
| A.13 | 통신 보안 | Communications Security |
| A.14 | 시스템 개발/유지보수 | System Acquisition, Development and Maintenance |
| A.15 | 공급자 관계 | Supplier Relationships |
| A.16 | 정보보안 사고 관리 | Information Security Incident Management |
| A.17 | 사업연속성관리(BCM)의 정보보안 측면 | Business Continuity Management |
| A.18 | 준거성(컴플라이언스) | Compliance |

## 2. Annex A vs 본문 조항(Clause) 구분

```
ISO 27001 표준
├── 본문 조항 (Clause 4~10, 필수 요구사항, PDCA 관리시스템)
│     4.조직상황 5.리더십 6.기획 7.지원 8.운용 
│     9.성과평가(모니터링·검토·내부감사 포함) 10.개선
│
└── Annex A (14개 영역, 통제 항목 카탈로그)
      실제 "무엇을 지켜야 하는지"의 구체적 통제 목록
```

**핵심 함정**: "모니터링/검토(Monitoring and Review)"는 **Annex A가 아니라 본문 9절(성과평가)** 소속 — 시험에서 "다음 중 Annex A 영역이 아닌 것은?" 문제의 단골 오답 함정

## 암기 팁
- **"정인자 접암물 운통개공 사업준"** (A.5~A.18 순서대로 앞글자)
  정책-인적자원-자산 / 접근통제-암호화-물리보안 / 운영-통신-개발 / 공급자-사고-사업연속성-준거성
- **"PDCA(관리)와 Annex A(실행목록)는 다른 층"** — 모니터링/검토/내부감사는 PDCA 소속

## 헷갈리는 포인트
- 시험에서 "모니터링", "검토", "내부감사" 같은 PDCA 관리개념을 Annex A 보기로 끼워넣어 헷갈리게 함 — 이건 본문 9절 소속이지 Annex A 아님
- A.7(인적자원보안)은 "사람 관리"이지 "조직 관리"(A.6)와 다름 — 채용/재직/퇴직 단계별 통제가 A.7

## 관련 기출/문제
- "다음 중 Annex A 통제영역이 아닌 것은?" → Monitoring and Review (본문 소속)
- Annex A 14개 영역 순서/이름 매칭
