# ISMS-P (정보보호 및 개인정보보호 관리체계 인증)

## 한줄 요약
> ISMS-P는 "관리체계 수립·운영(16항목)+보호대책 요구사항(64항목)+개인정보 처리단계별 요구사항(21항목)" 3개 영역, 총 101개 인증기준으로 구성되며, 유효기간 3년+매년 사후심사를 받아야 한다.

## 1. 법적 근거 및 인증기관

| 항목 | 내용 |
|---|---|
| 법적 근거 | 정보통신망법 + 개인정보보호법 |
| 정책기관 | 과학기술정보통신부 + 개인정보보호위원회(공동) |
| 실무 인증기관 | KISA(한국인터넷진흥원) |

## 2. 인증기준 3개 영역 (총 101개)

| 영역 | 항목 수 | 내용 |
|---|---|---|
| 1. 관리체계 수립 및 운영 | 16항목 | 정책수립, 위험관리, 내부감사 등 PDCA 전반 |
| 2. 보호대책 요구사항 | 64항목 | 접근통제, 암호화, 물리보안, 사고대응 등 |
| 3. 개인정보 처리단계별 요구사항 | 21항목 | 수집→이용→제공→파기 단계별 개인정보 보호조치 |

**합계**: 16+64+21 = **101개 인증기준**

## 3. 인증 절차 흐름

```
[신청] → [계약] → [심사(서면+현장)] → [인증위원회 심의] → [인증서 발급]
                                                              │
                                                              ▼
                                                     [유효기간 3년]
                                                              │
                                          매년 사후심사(자격 유지 확인)
```

## 4. ISMS vs ISMS-P

| 구분 | ISMS | ISMS-P |
|---|---|---|
| 범위 | 정보보호 관리체계만 | 정보보호 **+ 개인정보보호** 관리체계 |
| 인증기준 | 관리체계(16)+보호대책(64) = 80개 | ISMS 80개 **+ 개인정보 처리단계(21)** = 101개 |
| 대상 | 정보보호 중심 조직 | 개인정보를 대량 처리하는 조직(온라인서비스 등) |

## 5. 의무대상자 (일정 기준 이상 사업자는 의무 인증)

- 정보통신서비스 매출액, 이용자 수 등 법령상 정해진 기준을 초과하는 사업자는 **의무적으로** ISMS 또는 ISMS-P 인증을 받아야 함

## 암기 팁
- **"16-64-21 = 101"**: 관리체계(16)+보호대책(64)+개인정보(21) = 101개, 숫자 리듬으로 암기
- **"ISMS-P = ISMS + 개인정보(Privacy)"** — P가 붙으면 개인정보 처리단계까지 포함
- **"3년 인증, 매년 숙제(사후심사)"**

## 헷갈리는 포인트
- ISMS-P가 ISMS보다 **완전히 다른 별개의 인증**이 아니라, **ISMS 기준을 포함하면서 개인정보 영역이 추가**된 구조 — "상위 확장판" 개념
- 인증 유효기간(3년)과 사후심사(매년) 주기를 혼동하기 쉬움 — 3년마다 재인증, 그 사이 매년 유지 여부 확인(사후심사)
- 정책기관(과기정통부+개인정보위)과 실무 인증기관(KISA)의 역할이 다름

- ISMS vs ISMS-P 차이

- 정책기관 vs 실무기관(KISA) 구분
