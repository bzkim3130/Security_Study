# RAID (디스크 저장 방식)

## 한줄 요약
> RAID 0은 속도만, RAID 1은 미러링, RAID 5/6는 패리티로 내결함성, RAID 10은 미러링+스트라이핑 조합이다.

## 1. RAID 레벨 비교표

| 레벨 | 방식 | 최소 디스크 | 내결함성 | 용량 효율 | 특징 |
|---|---|---|---|---|---|
| RAID 0 | 스트라이핑 | 2 | 없음 | 100% | 속도 최고, 하나만 고장나도 전체 손실 |
| RAID 1 | 미러링 | 2 | 1개 고장까지 | 50% | 동일 데이터 복제, 안전하지만 용량 절반 |
| RAID 5 | 스트라이핑+패리티 | 3 | 1개 고장까지 | (n-1)/n | 패리티 분산 저장, 균형잡힌 선택 |
| RAID 6 | 스트라이핑+이중패리티 | 4 | 2개 고장까지 | (n-2)/n | RAID5보다 안전, 쓰기 성능 다소 낮음 |
| RAID 10 (1+0) | 미러링 후 스트라이핑 | 4 | 미러 그룹마다 1개 | 50% | 속도+안전성 둘 다, 비용 높음 |

## 2. 구조 도식화

```
RAID 0 (스트라이핑)
Disk1: A1 A3 A5     Disk2: A2 A4 A6
→ 데이터를 번갈아 저장, 속도 빠름, 중복 없음(고장나면 복구 불가)

RAID 1 (미러링)
Disk1: A1 A2 A3     Disk2: A1 A2 A3 (완전 복제)
→ 하나 고장나도 다른 하나로 복구 가능

RAID 5 (패리티 분산)
Disk1: A1  A2  Pc      Disk2: A3  Pb  A5      Disk3: Pa  A4  A6
→ 패리티(P)를 디스크마다 돌아가며 분산 저장

RAID 10 (미러링+스트라이핑)
[Disk1+Disk2 미러 그룹] + [Disk3+Disk4 미러 그룹] → 두 그룹을 스트라이핑
```

## 3. 핵심 용어

- **스트라이핑 (Striping)**: 데이터를 여러 디스크에 나눠 분산 저장 → 속도 향상, 내결함성 없음
- **미러링 (Mirroring)**: 동일 데이터를 다른 디스크에 그대로 복제 → 안전하지만 용량 절반
- **패리티 (Parity)**: 오류 검출/복구용 계산값을 별도 저장 → 디스크 하나 고장나도 나머지로 복원 가능
- **내결함성 (Fault Tolerance)**: 일부 디스크가 고장나도 데이터/서비스가 유지되는 능력

## 4. 용량 효율 공식

```
RAID 5 용량 효율 = (n-1)/n   (n = 디스크 개수)
RAID 6 용량 효율 = (n-2)/n
```
예: 디스크 4개로 RAID 5 구성 시 → (4-1)/4 = 75% 사용 가능

## 암기 팁
- **"0은 속도만(0=제로 안전장치), 1은 복제(1:1 미러), 5는 패리티 하나, 6은 패리티 둘, 10은 둘 다"**
- 숫자가 클수록(5,6) 패리티 방식, 1과 10은 미러링 계열
- **"RAID 5는 디스크 1개까지, RAID 6는 2개까지 고장 버팀"** — 숫자와 안전마진 매칭

## 헷갈리는 포인트
- RAID 0은 "RAID"라는 이름이 붙어있지만 **내결함성이 전혀 없음** (오히려 디스크 늘어날수록 고장 확률 증가)
- RAID 10과 RAID 5의 차이: RAID 10은 미러링 기반(속도+안전, 비용 큼), RAID 5는 패리티 기반(효율적, 쓰기 성능은 상대적으로 느림)

## 관련 기출/문제
- RAID 레벨별 최소 디스크 수, 내결함성 비교
- RAID 5/6 용량 효율 계산 문제
- 스트라이핑/미러링/패리티 용어 구분
