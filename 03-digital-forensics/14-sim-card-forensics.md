# SIM 카드 포렌식 분석

## 한줄 요약
> SIM/UICC는 MF-DF-EF 파일계층 구조를 가지며, IMSI(가입자식별)·ICCID(카드고유번호)·MSISDN(전화번호)을 혼동하지 않는 것과 Ki(인증키)는 절대 추출 불가능하다는 게 핵심이다.

## 1. SIM/UICC/USIM 관계

```
UICC (범용 IC카드, 물리적 카드 자체)
   └── USIM (그 카드 안에 저장된 애플리케이션, 3G/4G/5G 가입자 인증 담당)
        (2G 시절엔 SIM이라 불렀고, 지금은 USIM이 사실상 표준)
```

## 2. 핵심 식별자 3종 (시험 단골 함정)

| 식별자 | 의미 | 저장 위치 | 특징 |
|---|---|---|---|
| IMSI | International Mobile Subscriber Identity(국제 가입자 식별번호) | EF_IMSI | 통신사 네트워크에서 가입자를 식별하는 고유번호 |
| ICCID | Integrated Circuit Card ID(집적회로카드 고유번호) | 카드 표면 인쇄+EF | **SIM 카드 자체**의 고유 시리얼번호(전화번호 아님) |
| MSISDN | Mobile Station ISDN Number(전화번호) | EF_MSISDN(선택적 저장) | 우리가 아는 **"전화번호"** |

**핵심**: IMSI는 "가입자"를, ICCID는 "카드"를, MSISDN은 "전화번호"를 식별 — 셋 다 다른 대상을 가리킴

## 3. 파일 시스템 계층 구조 (MF-DF-EF)

```
MF (Master File, 최상위 루트)
 ├── DF (Dedicated File, 디렉터리 역할)
 │     ├── EF_IMSI (가입자 식별번호)
 │     ├── EF_ADN (전화번호부, Abbreviated Dialing Numbers)
 │     ├── EF_SMS (문자메시지 저장)
 │     └── EF_LOCI (마지막 접속 기지국 위치정보)
 └── DF (다른 애플리케이션 영역)
```

## 4. 주요 EF(Elementary File)의 포렌식적 의미

| EF | 담긴 정보 | 포렌식 가치 |
|---|---|---|
| EF_ADN | 전화번호부 | 연락처 관계 파악 |
| EF_SMS | 문자메시지(수신함/발신함) | **삭제된 SMS도 상태바이트만 바뀌고 실제 내용은 남아있어 복구 가능**한 경우 많음 |
| EF_LOCI | 마지막으로 등록된 기지국 위치 | **실시간 GPS 아님** — "마지막 접속 시점"의 대략적 위치만 알 수 있음 |
| EF_IMSI | 가입자 식별번호 | 가입자 특정 |

## 5. 포렌식 절차

```
[네트워크 격리(페러데이백)] → [SIM 리더기로 이미징]
        → [해시값 계산(무결성 검증)] → [파일 파싱/분석]
```

## 암기 팁
- **"국카전"**: IMSI(**국**제가입자)-ICCID(**카**드번호)-MSISDN(**전**화번호)
- **"Ki는 절대 못 꺼낸다"** — 인증키(Ki)는 SIM 내부에서 연산에만 쓰이고 **외부로 추출 불가능**(추출 가능하면 복제폰 만들 수 있으므로 설계상 원천 차단)
- **EF_LOCI = "마지막 문자메시지 남기고 떠난 곳"** — 실시간 위치추적 아님, 마지막 접속 기록일 뿐
- **삭제된 SMS = "휴지통 아이콘만 바뀐 것"** — 상태바이트(플래그)만 "삭제됨"으로 바뀌고 실제 데이터는 남아있는 경우 많아 복구 가능

## 헷갈리는 포인트
- IMSI/ICCID/MSISDN을 서로 혼동하기 쉬움 — 각각 가입자/카드/전화번호로 대상이 다름
- Ki(인증키)를 "암호화되어 저장되어 있으니 언젠가 복호화하면 꺼낼 수 있다"고 착각하기 쉬움 — 설계상 **절대 추출 불가능**(SIM 내부 연산 전용)
- EF_LOCI를 실시간 GPS 위치추적 데이터로 착각하기 쉬움 — 실제로는 **가장 최근 접속한 기지국 정보**일 뿐

## 관련 기출/문제
- IMSI/ICCID/MSISDN 각각의 정의와 구분
- Ki 인증키의 추출 불가능성
- 삭제된 SMS의 복구 가능성 원리
- EF_LOCI가 실시간 위치가 아니라는 점
