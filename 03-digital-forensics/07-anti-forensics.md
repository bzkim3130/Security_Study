# 안티포렌식 (데이터 은닉, 삭제 복구)

## 한줄 요약
> 안티포렌식은 "증거를 숨기거나(은닉), 못 쓰게 만들거나(삭제/파괴), 분석을 방해하는(난독화)" 모든 기법을 말하며, 조사관은 그 반대로 흔적을 복구·탐지해야 한다.

## 1. 안티포렌식 기법 분류

```
안티포렌식
├── 데이터 은닉 (Hiding)
│     예: 스테가노그래피, 슬랙공간 은닉, 파일 확장자 위조
│
├── 데이터 삭제/파괴 (Destruction)
│     예: 파일 완전삭제(Wiping), 디가우징, 물리적 파괴
│
├── 안티포렌식 도구 사용 (Trail Obfuscation)
│     예: 타임스탬프 조작(Timestomping), 로그 삭제
│
└── 암호화 (Encryption)
      예: 전체디스크암호화(FDE), 컨테이너 암호화
```

## 2. 데이터 은닉 기법

| 기법 | 원리 |
|---|---|
| 스테가노그래피 | 이미지/오디오 파일 속 데이터에 눈에 안 띄게 정보 은닉 |
| 슬랙 공간(Slack Space) 활용 | 파일이 클러스터를 다 못 채우고 남는 여유 공간에 데이터 숨김 |
| ADS (Alternate Data Stream, NTFS) | 하나의 파일에 보이지 않는 추가 데이터 스트림을 붙여 은닉 |
| 확장자 위조 | 실행파일을 이미지 확장자(.jpg)로 위장 등 |

## 3. 삭제된 데이터의 복구 가능성

- 파일을 "삭제"해도 실제 데이터는 즉시 지워지지 않고, **파일시스템의 인덱스(MFT 등)에서 참조만 제거**되는 경우가 많음 → 덮어쓰기 전까지는 복구 가능
- **완전삭제(Wiping)**: 무작위 데이터로 여러 번 덮어써서 복구 불가능하게 만드는 기법 (예: DoD 5220.22-M 표준)
- **디가우징(Degaussing)**: 강한 자기장으로 자기matter 저장매체(HDD 등) 데이터를 물리적으로 파괴 (SSD에는 효과 없음)

## 4. 타임스탬프 조작 (Timestomping)

파일의 생성/수정/접근 시각(MACE: Modified, Accessed, Created, Entry modified)을 인위적으로 변경해 수사 타임라인을 교란하는 기법.

**대응**: 파일시스템 저널(NTFS의 $LogFile, $UsnJrnl) 등 이중 기록을 대조해서 조작 여부 탐지 가능

## 암기 팁
- **안티포렌식 4분류**: "은닉-삭제-교란-암호화"
- **삭제 ≠ 소멸**: "삭제 버튼은 목차만 지우는 것, 실제 내용은 덮어쓰기 전까지 남아있다"
- **디가우징은 HDD에만 효과, SSD엔 안 통함** (SSD는 별도 삭제기법 필요)

## 헷갈리는 포인트
- 슬랙 공간과 ADS는 둘 다 "숨기는" 기법이지만, 슬랙공간은 파일시스템의 여유공간을 이용하는 것이고 ADS는 NTFS 고유 기능(추가 스트림)을 이용하는 것 — 원리가 다름
- 타임스탬프 조작은 파일 자체 메타데이터만 바꾸는 것이라, 파일시스템 저널 같은 별도 로그와 대조하면 들통날 수 있음

## 관련 기출/문제
- 안티포렌식 기법 분류 매칭
- 삭제된 파일이 왜 복구 가능한지 원리
- 디가우징이 SSD에 효과 없는 이유
