# 스마트폰 포렌식 (iOS vs Android)

## 한줄 요약
> 추출방식은 논리(백업기반)→파일시스템(탈옥/익스플로잇 필요)→물리(칩오프/JTAG, 비트단위복사) 순으로 깊어지며, iOS는 Secure Enclave+강제암호화 때문에 물리추출이 훨씬 어렵고, Android는 기종별 파일시스템(F2FS/EXT4) 다양성이 변수다.

## 1. 3대 추출 방식

| 방식 | 원리 | 난이도/특징 |
|---|---|---|
| 논리적 추출(Logical) | 백업 API(iTunes백업, ADB백업)를 통해 접근 | 가장 쉬움, 얻을 수 있는 정보 제한적 |
| 파일시스템 추출(File System) | 탈옥(Jailbreak)/루팅 또는 익스플로잇으로 파일시스템 전체 접근 | 중간 난이도, 삭제된 데이터 일부 접근 가능 |
| 물리적 추출(Physical) | 칩오프(Chip-off) 또는 JTAG로 저장소 자체를 비트단위 복사 | 가장 어려움, 가장 많은 정보(삭제데이터 포함) 획득 가능 |

```
논리적(쉬움, 정보적음) → 파일시스템(중간) → 물리적(어려움, 정보많음)
```

## 2. iOS 포렌식 특징

| 요소 | 내용 |
|---|---|
| Secure Enclave | 암호화키를 별도 격리된 보안 프로세서에서 관리 → 칩오프해도 키 없이는 복호화 불가 |
| FDE/FBE | 전체디스크암호화(Full Disk Encryption)/파일기반암호화(File-Based Encryption) 강제 적용 |
| 탈옥(Jailbreak) 필요성 | 파일시스템 접근하려면 보통 탈옥 필요 → **포렌식 무결성 훼손 우려** |
| 백업 방식 | iTunes/Finder 백업(암호화 여부 선택 가능) |

## 3. Android 포렌식 특징

| 요소 | 내용 |
|---|---|
| 파일시스템 다양성 | 제조사/버전별로 EXT4, F2FS 등 상이 → 분석 도구 호환성 이슈 |
| 루팅 필요성 | 깊은 접근을 위해 루팅 필요한 경우 많음 |
| ADB 백업 | `adb backup` 명령으로 논리적 추출 가능(단, 최신버전은 제한 늘어남) |
| Secure Enclave 대응 | TEE(Trusted Execution Environment) — 제조사별로 구현 상이 |

## 4. iOS vs Android 비교

| 구분 | iOS | Android |
|---|---|---|
| 물리추출 난이도 | 매우 높음(강제암호화+Secure Enclave) | 상대적으로 다양(기종별 편차 큼) |
| 파일시스템 | APFS(통일됨) | EXT4/F2FS 등 기종별 상이 |
| 표준화 정도 | 높음(폐쇄적 생태계) | 낮음(개방적, 제조사 다양) |
| 상용 포렌식 도구 | Cellebrite, Axiom 등 | 동일 도구가 Android도 지원(단, 기종별 지원범위 다름) |

## 5. 증거 보전 절차

```
[기기 확보] → [전원상태 유지 판단] → [페러데이백 격리(네트워크 차단)]
     → [배터리 방전 방지 조치] → [이미징(추출)] → [해시검증]
```

## 암기 팁
- **"논파물"**: **논**리적 → **파**일시스템 → **물**리적 순서로 추출 난이도/깊이 증가
- **"차전배"**: **차**단(네트워크/페러데이백) → **전**원유지 → **배**터리(방전방지) 순서로 증거보전
- **"iOS는 금고 안에 또 금고(Secure Enclave)"** — 칩을 떼어내도 열쇠가 따로 잠겨있어서 못 엶
- **"Android는 사람마다 집 구조가 다름(파일시스템 다양성)"**

## 헷갈리는 포인트
- 논리적 추출을 "백업과 똑같다"고 오해하기 쉬움 — 논리추출은 백업 API를 **활용**하는 것이지, 사용자가 수동으로 만드는 백업과 완전히 동일하지 않을 수 있음
- 탈옥/루팅이 "포렌식에서 항상 필요하다"고 오해하기 쉬움 — 탈옥은 **파일시스템/물리 추출 시 필요할 수 있는 수단**이지만, 기기 원본상태를 변경시켜 **무결성 훼손 논란**이 있을 수 있어 신중히 접근
- iOS/Android 모두 "Secure Enclave/TEE"라는 유사 개념이 있지만 구현 방식과 성숙도가 다름

## 관련 기출/문제
- 3대 추출방식(논리/파일시스템/물리) 순서와 특징
- iOS Secure Enclave의 역할
- Android 파일시스템 다양성이 포렌식에 미치는 영향
- 탈옥/루팅의 필요성과 무결성 이슈
