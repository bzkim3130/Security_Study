# HBM (High Bandwidth Memory)

## 한줄 요약
> HBM은 DRAM을 수직으로 적층하고 TSV로 연결해, 낮은 클럭에서도 매우 넓은 대역폭을 내는 고성능 메모리로 GPU/AI 가속기에 쓰인다.

## 1. 개요

여러 DRAM 다이(die)를 수직 적층하고 **TSV(실리콘 관통전극)**로 연결해 매우 넓은 대역폭을 제공하는 메모리 규격. JEDEC 표준화, 주로 GPU/AI 가속기/HPC에 사용.

## 2. 등장 배경

기존 GDDR은 클럭을 높여 대역폭 확보 → 전력·발열 크고 배선(핀 수) 한계. HBM은:
- 수평이 아닌 **수직 적층** 구조
- 매우 **넓은 버스 폭**으로 낮은 클럭에서도 높은 대역폭
- 프로세서 바로 옆(위)에 배치해 물리적 거리 최소화

## 3. 핵심 구조

```
[프로세서(GPU)] ─── [인터포저(Interposer)] ─── [HBM 스택]
                                                    │
                                          여러 층 DRAM 다이
                                          (TSV로 수직 연결)
                                                    │
                                          최하단: 베이스(로직) 다이
```

- **TSV**: 여러 층 DRAM 다이를 관통하는 미세 수직 전극, 층 간 데이터를 짧은 경로로 직접 연결 → 지연시간↓ 전력효율↑
- **인터포저**: HBM 스택과 프로세서를 하나의 패키지 기판 위에 올리는 실리콘 중간층, 초미세 배선으로 넓은 버스(1024비트+) 구현 → 이 구조를 **2.5D 패키징**이라 함

## 4. HBM vs GDDR vs DDR

| 항목 | HBM | GDDR | DDR |
|---|---|---|---|
| 구조 | 수직 적층 | 평면(단일칩) | 평면(단일칩) |
| 버스 폭 | 매우 넓음(1024비트+) | 좁음(32비트 등) | 좁음 |
| 클럭 | 낮음 | 높음 | 중간 |
| 대역폭 | 매우 높음 | 높음 | 낮음~중간 |
| 전력 효율 | 우수 | 보통 | 보통 |
| 실장 면적 | 작음 | 큼 | 큼 |
| 주 용도 | GPU/AI가속기/HPC | 그래픽카드 | 범용 시스템 메모리 |

## 5. 장단점

**장점**: 높은 대역폭을 낮은 클럭·전력으로 달성 / 작은 실장 면적 / 프로세서와 물리적 거리 단축(지연시간↓)

**단점**: 제조공정 복잡(TSV, 인터포저)으로 비용↑ / 적층 구조 특성상 발열 관리 어려움 / 용량 확장 유연성 낮음

## 암기 팁
- **"HBM = 아파트(수직 적층), GDDR/DDR = 단독주택(평면)"**
- **TSV = 층간 엘리베이터(수직 연결 통로)**
- **버스 폭 넓다 = 클럭 안 높여도 됨(전력 절약)** — HBM의 핵심 트레이드오프

## 헷갈리는 포인트
- HBM이 "속도(클럭)"가 빠른 게 아니라, **버스 폭이 넓어서** 총 대역폭이 높은 것 — 클럭 자체는 오히려 GDDR보다 낮음
- 인터포저(2.5D 패키징)와 TSV 적층(3D 적층)은 다른 층위의 기술 — TSV는 다이끼리 수직연결, 인터포저는 다이 스택과 프로세서를 옆에 나란히 배치하는 중간 기판
