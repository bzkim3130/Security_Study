# 메모리 종류 정리 (ROM/RAM 계열)

## 한줄 요약
> 메모리는 휘발성(RAM)과 비휘발성(ROM)으로 나뉘고, 포렌식에서는 "전원 꺼지면 데이터가 사라지는가"가 핵심 판단 기준이며, EPROM(자외선)과 EEPROM(전기)의 소거방식 차이, SRAM(캐시)과 DRAM(주기억)의 리프레시 필요여부가 자주 나온다.

## 1. 비휘발성 메모리 (ROM 계열)

| 종류 | 특징 | 재기록 방식 |
|---|---|---|
| Mask ROM | 제조 시 데이터 고정, 이후 변경 불가 | 불가능 |
| PROM | 사용자가 1회 기록 가능 | 1회성(퓨즈 태움) |
| EPROM | **자외선(UV)**으로 지우고 재기록 | UV 조사 후 재기록 |
| EEPROM | **전기적**으로 지우고 재기록(바이트 단위) | 전기적, 반복 가능 |
| Flash Memory | EEPROM 발전형, **블록 단위** 소거 | 전기적, 대용량화 |

## 2. 휘발성 메모리 (RAM 계열)

| 종류 | 특징 | 속도/용도 |
|---|---|---|
| SRAM | 플립플롭 구조, 리프레시 불필요 | 빠름, 비쌈 → **캐시 메모리(L1/L2/L3)** |
| DRAM | 커패시터 구조, 주기적 리프레시 필요 | 느림, 저렴 → **주기억장치** |
| HBM | DRAM을 수직 적층(TSV) + 광대역 인터페이스 | 초고대역폭, GPU/AI 반도체용 |

## 3. 분류 다이어그램

```
메모리(Memory)
├── ROM(비휘발성)
│    Mask ROM → PROM(1회) → EPROM(UV재기록) → EEPROM(전기,바이트) → Flash(전기,블록)
│    (오른쪽으로 갈수록 재기록이 쉬워짐)
│
└── RAM(휘발성)
     ├── SRAM (플립플롭, 리프레시불필요, 캐시용)
     ├── DRAM (커패시터, 리프레시필요, 주기억장치)
     └── HBM (DRAM 적층+광대역, GPU/AI용)
```

## 암기 팁
- **"PEE-Flash"** (재기록 가능해지는 순서): **P**ROM(1회) → **E**PROM(UV) → **E**EPROM(전기,바이트) → **Flash**(전기,블록) — 갈수록 "지우기 쉬워진다"
- **SRAM = Static = 안정적 → 캐시(빠르지만 비쌈)**
- **"D는 Dynamic, D는 Dying"** — DRAM은 계속 재충전 안 하면 데이터가 죽음(사라짐) → 리프레시 필요
- **HBM = "High-rise(고층건물) Bandwidth Memory"** — DRAM을 아파트처럼 수직으로 쌓아올린 것(적층)+광대역

## 헷갈리는 포인트
- **EPROM vs EEPROM**: EPROM은 **자외선(물리적)**, EEPROM은 **전기적** 소거 — "UV 램프로 지워야 한다"는 조건이 나오면 EPROM
- **SRAM vs DRAM**: SRAM=리프레시 **불필요**(플립플롭이라 상태 유지), DRAM=리프레시 **필요**(커패시터 전하 누설)
- **HBM vs DRAM**: HBM은 별개의 메모리 종류가 아니라 **DRAM을 패키징한 방식**(TSV 적층) — "HBM은 DRAM의 일종"이 핵심
- **Flash vs EEPROM**: Flash는 EEPROM의 발전형이지만 **블록 단위 소거**라 EEPROM(바이트 단위)보다 빠르고 대용량

## 관련 기출/문제
- 포렌식에서 "전원 차단 시 데이터 소실 여부"를 묻는 문제 → RAM(휘발성) vs ROM(비휘발성) 구분이 핵심
- BIOS/펌웨어 저장 메모리로 뭐가 쓰이는지(과거 Mask ROM → 요즘은 Flash/EEPROM 계열) 함정 문제
- CPU 캐시(L1/L2/L3)에 쓰이는 메모리 = **SRAM**(DRAM 아님) — 자주 나오는 헷갈림 포인트
- RAM 덤프(Live Forensics)가 중요한 이유 — 휘발성이라 전원 꺼지기 전 수집 필요
