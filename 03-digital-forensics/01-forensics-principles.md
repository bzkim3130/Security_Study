# 포렌식 기본 원칙 (무결성, 연계보관성)

## 한줄 요약
> 디지털 포렌식의 4대 원칙은 정당성·재현성·신속성·연계보관성이며, 이 중 무결성과 연계보관성(Chain of Custody)이 법정 증거능력의 핵심이다.

## 1. 디지털 포렌식 4대 원칙

| 원칙 | 의미 |
|---|---|
| <mark>정당성</mark>의 원칙 | 적법한 절차(영장 등)로 증거를 수집해야 함 — 위법수집증거는 증거능력 없음 |
| 재현성의 원칙 | 동일한 조건에서 동일한 절차를 거치면 같은 결과가 나와야 함 |
| 신속성의 원칙 | 휘발성 데이터(메모리 등)는 시간이 지나면 사라지므로 신속히 수집 |
| 연계보관성의 원칙 (Chain of Custody) | 증거 수집부터 법정 제출까지 이동 경로와 관리자를 모두 기록·추적 가능해야 함 |

## 2. 무결성 (Integrity)

- 증거가 수집된 이후 **변경되지 않았음을 증명**하는 것
- 대표 방법: **해시값(MD5/SHA-256) 비교**
  - 최초 수집 시 해시값 계산 → 이후 분석 과정마다 동일한 해시값 나오는지 검증
- 원본은 절대 직접 분석하지 않고, **이미징(복제본)** 을 만들어 분석 (원본 보존)

## 3. 연계보관성 (Chain of Custody, CoC)

증거가 "누구 손을 거쳐 어디로 이동했는지" 끊김 없이 기록하는 것.

```
[증거 수집] → [포장/봉인] → [이송] → [보관] → [분석] → [법정 제출]
     │            │           │        │         │           │
   기록①        기록②       기록③    기록④     기록⑤       기록⑥
   (누가, 언제, 어떻게 처리했는지 매 단계 기록)
```

**CoC 기록에 포함되어야 할 항목**
- 증거 식별 정보 (증거번호, 종류)
- 수집 일시/장소/수집자
- 이동 경로 (누가 언제 어디로 옮겼는지)
- 보관 장소 및 보관 책임자
- 접근(열람) 기록

## 암기 팁
- **4대 원칙 두문자**: "정.재.신.연" (정당성-재현성-신속성-연계보관성)
- **무결성 = "복제해서 보고, 해시로 확인"**
- **연계보관성 = "택배 배송조회처럼 증거 이동경로를 전부 남긴다"**

## 헷갈리는 포인트
- 무결성은 "증거 내용이 안 바뀌었다"는 증명, 연계보관성은 "증거를 누가 어떻게 다뤘는지 경로"를 증명 — 둘 다 중요하지만 증명 대상이 다름
- 원본을 직접 분석하면 원칙 위반 → 반드시 이미징(비트 단위 복제) 후 사본으로 분석

## 관련 기출/문제
- 4대 원칙 이름과 의미 매칭
- 무결성 검증에 해시값을 쓰는 이유
- Chain of Custody 기록 항목
