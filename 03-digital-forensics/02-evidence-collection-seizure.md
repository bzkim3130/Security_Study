# 증거수집 / 압수수색

## 한줄 요약
> 디지털 증거 압수수색은 원칙적으로 "현장에서 저장매체 자체가 아닌 필요한 정보만" 복제·출력해서 가져오는 것이 원칙이다 (형사소송법 제106조 제3항).

## 1. 압수수색 기본 원칙

| 원칙 | 내용 |
|---|---|
| 영장주의 | 원칙적으로 법원이 발부한 압수수색 영장 필요 |
| 범위의 특정성 | 영장에 기재된 범위 내에서만 압수 가능 |
| 정보 저장매체 압수 제한 (형사소송법 106조③) | 원칙: 필요한 부분만 출력·복제 / 예외: 범위 특정 곤란하거나 협조 없으면 저장매체 자체 압수 가능 |
| 참여권 보장 | 피압수자(소유자 등)에게 압수수색 과정 참여 기회 부여 |
| 압수목록 교부 | 압수 후 목록을 피압수자에게 교부해야 함 |

## 2. 압수수색 절차 흐름

```
[영장 청구] → [영장 발부] → [현장 도착/제시] → [범위 내 증거 수색]
                                                        │
                          ┌─────────────────────────────┘
                          ▼
              필요한 정보만 특정 가능? 
                    │              │
                   Yes             No / 협조 곤란
                    │              │
              [출력·복제(원칙)]  [저장매체 자체 반출(예외)]
                    │              │
                    └──────┬───────┘
                           ▼
                 [압수목록 작성·교부] → [피압수자 참여권 보장]
```

## 3. 디지털 증거 특유의 고려사항

- **원본성**: 저장매체 원본이 아닌 이미징 사본으로 분석 (무결성 유지)
- **휘발성 데이터 우선순위**: 메모리(RAM) > 네트워크 연결상태 > 프로세스 > 디스크 순으로 휘발성이 높은 것부터 수집 (Order of Volatility)
- **암호화된 매체**: 복호화 협조를 구하거나, 협조 거부 시 법적 절차에 따른 처리 필요

## 암기 팁
- **"매체 자체보다 정보 자체가 원칙"** — 형사소송법 106조③ 핵심
- **압수 4단계**: "영장 → 수색 → 압수(출력/복제 원칙) → 목록교부"
- 휘발성 순서: **"메모리 → 연결상태 → 프로세스 → 디스크"** (빨리 사라지는 것부터 먼저 수집)

## 헷갈리는 포인트
- "저장매체 자체를 압수"하는 것은 **원칙이 아니라 예외** — 범위 특정이 어렵거나 협조 없을 때만 가능
- 압수수색 영장은 특정 범죄사실과 관련된 범위 내에서만 유효 — 무관한 정보까지 마구잡이로 가져가면 위법수집증거가 될 수 있음

## 관련 기출/문제
- 형사소송법 106조③의 원칙과 예외 구분
- 압수수색 시 피압수자 권리(참여권, 압수목록 교부)
- 휘발성 데이터 수집 우선순위
