# Windows 보안 / 인증 흐름 (Winlogon, LSA, SAM, SRM, Kerberos)

## 한줄 요약
> 로그온 화면(Winlogon) → 계정정보 입력(Credential Provider) → 인증 총괄(LSA) → 계정대조(SAM/Kerberos) → 접근토큰 발급 → 리소스 접근시마다 권한검사(SRM) 순서로 진행된다.

## 1. 핵심 구성요소

| 구성요소 | 역할 | 비유 |
|---|---|---|
| Winlogon | 로그온 화면 띄움, 보안 인터럽트(Ctrl+Alt+Del) 처리 | 현관문 |
| Credential Provider (구 GINA) | 사용자 ID/암호 입력받는 UI | 초인종/신분증 제출구 |
| LSA (Local Security Authority) | 인증 전체 총괄, 토큰 생성, 보안 정책 관리 | 경비실 |
| SAM (Security Account Manager) | 로컬 계정과 암호(해시) 저장 DB | 방문자 명부 |
| 인증 패키지 | 실제 인증 로직 — 로컬: MSV1_0 / 도메인: Kerberos | 신원조회 시스템 |
| SRM (Security Reference Monitor) | 인증 후 리소스 접근 시 권한 검사(토큰 vs ACL), 감사 로그 기록 | 방마다 있는 열쇠 검사관 |

## 2. 인증 흐름도

```
  [사용자]
     │ Ctrl+Alt+Del / 로그온 시도
     ▼
┌───────────┐
│ Winlogon  │  ← 로그온 화면 띄움, 보안 인터럽트 감지
└─────┬─────┘
      │ 인증정보 입력 요청
      ▼
┌──────────────────┐
│ Credential        │  ← ID/PW 입력받는 UI
│ Provider          │
└─────┬─────────────┘
      │ 입력된 계정정보 전달
      ▼
┌──────────────────┐         ┌───────────────────┐
│      LSA          │◄──────►│  인증 패키지         │
│  (인증 총괄)        │         │ 로컬: MSV1_0       │
│                    │         │ 도메인: Kerberos    │
└─────┬─────────────┘         └───────────────────┘
      │ 계정/암호 대조
      ▼
┌──────────────────┐
│      SAM           │  ← 로컬 계정+암호해시 DB (도메인은 AD)
└─────┬─────────────┘
      │ 인증 성공
      ▼
┌──────────────────┐
│  액세스 토큰 발급     │
└─────┬─────────────┘
      │ 리소스 접근 시마다
      ▼
┌──────────────────┐
│      SRM            │  ← 토큰 vs ACL 비교 → 허용/거부 → 감사 로그 기록
└──────────────────┘
```

## 암기 팁
- **인증 흐름 순서**: "윈 → 크레 → 엘에스에이 → 샘 → 토큰 → 에스알엠"
  (문 두드리고(Win) → 신분증 내고(Cre) → 경비실 확인(LSA) → 명부 대조(SAM) → 열쇠 받고(토큰) → 방마다 검사(SRM))
- **문지기 비유로 스토리텔링**: "경비실(LSA)이 명부(SAM) 보고 확인하면, 문마다 있는 검사관(SRM)이 열쇠(토큰) 검사한다"

## 헷갈리는 포인트
- SAM은 **로컬 계정** 저장용, 도메인 환경에서는 SAM 대신 **AD(Active Directory)**가 그 역할을 함
- LSA는 인증을 "직접 수행"하는 게 아니라 **인증 패키지(MSV1_0/Kerberos)에 위임하고 총괄 관리**하는 역할
- SRM은 로그온 시점이 아니라 **로그온 이후 리소스 접근할 때마다** 매번 검사하는 지속적 역할

## 관련 기출/문제
- 각 구성요소의 역할 매칭 문제
- 로컬 인증(MSV1_0) vs 도메인 인증(Kerberos) 구분
- 인증 흐름 순서 나열 문제
