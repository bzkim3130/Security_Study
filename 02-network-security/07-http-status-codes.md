# HTTP 상태코드 암기법

## 한줄 요약
> 첫 자리 숫자로 카테고리를 구분한다: "1보류 2성공 3이동 4니탓 5내탓"

## 1. 큰 틀 암기법

| 첫자리 | 카테고리 | 의미 |
|---|---|---|
| 1xx | 정보 (Informational) | 아직 진행 중 |
| 2xx | 성공 (Success) | 잘 됐어 |
| 3xx | 리다이렉션 (Redirection) | 딴 데로 가 |
| 4xx | 클라이언트 오류 (Client Error) | 네 잘못 |
| 5xx | 서버 오류 (Server Error) | 내 잘못 |

**암기 문장**: "1보류 2성공 3이동 4니탓 5내탓"

## 2. 주요 코드별 정리

### 2xx (성공)
| 코드 | 의미 | 암기 |
|---|---|---|
| 200 | OK | 그냥 성공 |
| 201 | Created | 새로 생성됨 (POST 후) |
| 204 | No Content | 성공했지만 body 없음 |

### 3xx (리다이렉션)
| 코드 | 의미 | 암기 |
|---|---|---|
| 301 | 영구 이동 | Moved Permanently |
| 302 | 임시 이동 | Found (임시) |
| 304 | 캐시 사용 | Not Modified (변경 없음) |

### 4xx (클라이언트 오류)
| 코드 | 의미 | 암기 |
|---|---|---|
| 400 | Bad Request | 요청 자체가 잘못됨 |
| 401 | Unauthorized | 로그인 안 함 (인증 X) |
| 403 | Forbidden | 로그인했지만 권한 없음 (인가 X) |
| 404 | Not Found | 페이지 없음 |
| 405 | Method Not Allowed | 허용 안 된 메서드 |
| 409 | Conflict | 리소스 충돌 |
| 429 | Too Many Requests | 요청 과다 (레이트리밋) |

### 5xx (서버 오류)
| 코드 | 의미 | 암기 |
|---|---|---|
| 500 | Internal Server Error | 서버 내부 에러 |
| 502 | Bad Gateway | 중간 서버가 응답 못 받음 |
| 503 | Service Unavailable | 서버 다운/과부하 |
| 504 | Gateway Timeout | 응답 시간 초과 |

## 암기 팁
- **401 vs 403**: 401 = "누구세요?"(인증 안 됨), 403 = "누군지 알지만 안 돼"(권한 없음)
- **500 vs 502 vs 503**: 500 = 코드 자체가 터짐, 502 = 뒷단(gateway) 서버가 이상한 응답, 503 = 서버가 너무 바빠서 못 받음
- 숫자 앞자리로 카테고리 먼저 외우고, 400/401/403/404/500 다섯 개만 확실히 잡으면 대부분 커버됨

## 헷갈리는 포인트
- 401은 "인증(Authentication)" 문제, 403은 "인가(Authorization)" 문제 — 둘 다 "거부"지만 이유가 다름
- 502/503/504는 다 서버 쪽 문제지만, 502는 중간 서버 응답 이상, 503은 과부하, 504는 시간초과로 원인이 다름

## 관련 기출/문제
- 상태코드 카테고리(1xx~5xx) 매칭 문제
- 401/403 구분 문제
- 502/503/504 구분 문제
