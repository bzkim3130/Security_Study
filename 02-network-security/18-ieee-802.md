# IEEE 802 LAN 표준

## 한줄 요약
> 802.2(LLC)는 모든 MAC 위에 공통으로 얹히는 계층이고, 나머지 802.x는 매체별 MAC 방식을 정의하며 802.1X(인증)와 802.1Q(VLAN)를 헷갈리지 않는 게 핵심이다.

## 1. 주요 802.x 표준 목록

| 표준 | 이름 | 핵심 기능 |
|---|---|---|
| 802.1Q | VLAN | VLAN 태깅 |
| 802.1X | 포트기반 접근제어 | 포트 단위 인증(EAP 기반) |
| 802.1D | STP | 스패닝 트리(루프 방지) |
| 802.2 | LLC | 논리링크제어, MAC 상위 공통계층 |
| 802.3 | Ethernet | 유선랜, CSMA/CD |
| 802.11 | Wi-Fi | 무선랜, CSMA/CA |
| 802.15 | WPAN | 블루투스 등 근거리 무선 |
| 802.16 | WiMAX | 광대역 무선접속 |

## 2. OSI 계층 매핑

```
        데이터링크 계층(L2)
┌─────────────────────────────┐
│   802.2 (LLC) — 공통 상위계층   │  ← 모든 MAC 방식 위에 얹힘
├───────┬───────┬───────┬───────┤
│802.3  │802.11 │802.15 │802.16 │  ← 매체별 MAC 방식
│(유선)  │(무선)  │(WPAN) │(WiMAX)│
└───────┴───────┴───────┴───────┘
```

## 3. 헷갈리기 쉬운 두 쌍

### 802.1X vs 802.1Q
| 구분 | 802.1X | 802.1Q |
|---|---|---|
| 목적 | 포트 기반 **인증** | **VLAN** 태깅 |
| 핵심 기술 | EAP | VLAN Tag(4바이트) |
| 관련 용어 | Supplicant, Authenticator, RADIUS | Trunk, Access Port |

### CSMA/CD vs CSMA/CA
| 구분 | CSMA/CD | CSMA/CA |
|---|---|---|
| 적용 | 802.3 (유선 Ethernet) | 802.11 (무선 Wi-Fi) |
| 원리 | 충돌 감지(Collision Detection) 후 재전송 | 충돌 회피(Collision Avoidance), 사전 대기 |
| 이유 | 유선은 충돌을 감지할 수 있음 | 무선은 충돌 감지가 어려워 사전 회피 방식 사용 |

## 암기 팁
- **"X는 eXam(시험/인증), Q는 큐(가상 대기줄=VLAN)"**
- **"CD=Detection(감지, 유선이라 가능), CA=Avoidance(회피, 무선이라 미리 피함)"**
- **"802.2(LLC)는 모두의 지붕"** — 어떤 매체(3/11/15/16)든 그 위에 공통으로 얹힘

## 헷갈리는 포인트
- 802.1X(인증)와 802.1Q(VLAN)는 숫자만 비슷하고 **기능이 완전히 다름** — 시험 단골 함정
- LLC(802.2)는 매체 종류와 무관한 **공통 상위 계층**이지 특정 매체 전용 표준이 아님
