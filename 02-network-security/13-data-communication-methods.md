# 데이터 통신 방식 분류

## 한줄 요약
> 데이터 통신은 방향(단방향/반이중/전이중), 동기화(비동기/동기), 전송단위(직렬/병렬), 교환방식(회선/패킷교환) 4가지 기준으로 분류된다.

## 1. 전송 방향에 따른 분류

| 방식 | 설명 | 예시 |
|---|---|---|
| 단방향 (Simplex) | 한쪽에서만 전송 | TV방송, 라디오 |
| 반이중 (Half-Duplex) | 양쪽 다 가능하나 동시엔 한쪽만 | 무전기 |
| 전이중 (Full-Duplex) | 양쪽 동시 송수신 가능 | 전화, 대부분의 네트워크 통신 |

## 2. 동기화 방식에 따른 분류

| 방식 | 설명 |
|---|---|
| 비동기식 (Asynchronous) | 문자 단위로 Start/Stop bit를 붙여 전송, 구조 단순 |
| 동기식 (Synchronous) | 일정 클럭에 맞춰 블록 단위 전송, 별도 동기 신호 필요, 구조 복잡하지만 효율적 |

**함정**: "비동기식이 더 복잡해 보이지만(Start/Stop bit 추가) 구조적으로는 더 단순함" — 동기식이 별도 클럭 동기화 장치가 필요해 오히려 구현이 복잡함

## 3. 전송 단위에 따른 분류

| 방식 | 설명 |
|---|---|
| 직렬 전송 (Serial) | 한 줄로 비트를 순차 전송, 장거리에 유리 |
| 병렬 전송 (Parallel) | 여러 줄로 동시에 비트 전송, 단거리·고속에 유리하나 skew(비트별 도착시간 차이) 문제 |

## 4. 교환 방식에 따른 분류

```
스위칭(교환) 방식
├── 회선교환 (Circuit Switching)
│     예: 전화망(PSTN), ATM
│     → 통신 전 경로(가상회선) 확보, 연결지향적
│
└── 패킷교환 (Packet Switching)
      예: IP 네트워크, X.25
      → 데이터를 패킷 단위로 쪼개 전송, 경로 유동적
      ├── 데이터그램 방식: 매 패킷 독립적 경로(IP)
      └── 가상회선 방식: 논리적 경로 미리 설정(X.25, ATM)
```

| 구분 | 회선교환 | 패킷교환 |
|---|---|---|
| 연결 방식 | 연결지향(Connection-oriented) | IP는 비연결형(Connectionless) |
| 경로 | 고정(전용회선) | 유동적(공유) |
| 지연 | 일정함(전용 경로) | 가변적(혼잡시 지연) |
| 대표 예 | 전화망 | 인터넷(IP) |

## 암기 팁
- **방향**: "단방향(한쪽만), 반이중(번갈아), 전이중(동시양쪽)"
- **"IP는 데이터그램(비연결), TCP는 논리적으로 연결지향"** — 계층이 다름을 구분
- **X.25/ATM은 패킷교환이지만 가상회선 방식** — "패킷교환=항상 비연결"이라는 착각 주의

## 헷갈리는 포인트
- IP(네트워크계층)는 **비연결형(Connectionless)**, TCP(전송계층)는 **논리적으로 연결지향적** — 서로 다른 계층의 개념을 혼동하면 안 됨
- 비동기식이 "구조가 단순해서 오히려 실무에서 많이 쓰임", 동기식이 항상 더 우월한 게 아니라 상황에 맞게 선택

## 관련 기출/문제
- 4가지 분류 기준별 방식 매칭
- 회선교환 vs 패킷교환 특징 비교
- 비동기/동기식 구조 복잡도 비교
