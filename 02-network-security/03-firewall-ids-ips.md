# 방화벽 / IDS / IPS

## 한줄 요약
> 방화벽은 "규칙대로 막거나 허용", IDS는 "탐지만", IPS는 "탐지+즉시 차단"까지 한다.

## 1. 개념 비교

| 구분 | 방화벽 (Firewall) | IDS (침입탐지시스템) | IPS (침입방지시스템) |
|---|---|---|---|
| 동작 위치 | 네트워크 경계 (인라인) | 네트워크/호스트 (주로 미러링) | 네트워크 경계 (인라인) |
| 주요 기능 | 접근 통제 (허용/차단 규칙) | 이상 트래픽 탐지 후 알림 | 탐지 + 실시간 차단 |
| 실시간 차단 | O (규칙 기반) | X (탐지만, 사후 대응) | O |
| 판단 기준 | IP/포트/프로토콜 등 규칙 | 시그니처/이상행동 패턴 | 시그니처/이상행동 패턴 |

## 2. 방화벽 종류

```
방화벽 종류
├── 패킷 필터링 (Packet Filtering)
│     → IP/포트 기준, 가장 단순, 빠름
│
├── 상태 기반 검사 (Stateful Inspection)
│     → 연결 상태(세션) 추적, 더 정교함
│
└── 애플리케이션 계층 게이트웨이 (Application Gateway / Proxy)
      → 프로그램 단위 검사, 가장 정밀하지만 느림
```

## 3. IDS 탐지 방식

| 방식 | 원리 | 장점 | 단점 |
|---|---|---|---|
| 시그니처 기반 (오용탐지) | 알려진 공격 패턴(DB)과 비교 | 오탐 적음, 빠름 | 신종 공격 탐지 못함 |
| 이상탐지 (Anomaly Detection) | 정상 행위 기준선에서 벗어난 것 탐지 | 신종 공격도 탐지 가능 | 오탐(False Positive) 많음 |

## 4. IDS 위치에 따른 분류

- **NIDS (Network IDS)**: 네트워크 트래픽 전체를 감시
- **HIDS (Host IDS)**: 개별 호스트(서버/PC) 내부의 로그·파일 변경 등을 감시

## 암기 팁
- **"방화벽=문지기(규칙대로 통과여부), IDS=CCTV(보기만), IPS=경비원(보고 바로 제압)"**
- IDS 탐지방식: **"시그니처=몽타주 대조, 이상탐지=평소와 다른 행동 감지"**
- 방화벽 3단계: **"필터링(단순) → 상태기반(세션추적) → 애플리케이션(정밀)"** 순서로 정교해짐

## 헷갈리는 포인트
- IDS는 인라인이 아니라 **미러링(탭/스팬포트)으로 트래픽을 복사해서 관찰**하는 경우가 많음 → 그래서 실시간 차단이 어려움
- IPS는 인라인 배치라서 트래픽이 직접 통과함 → 오탐 시 정상 트래픽도 차단될 위험 있음

## 관련 기출/문제
- 방화벽 종류별 특징 비교 문제
- IDS vs IPS 차이 (탐지만 vs 탐지+차단)
- 시그니처 기반 vs 이상탐지 기반 구분
