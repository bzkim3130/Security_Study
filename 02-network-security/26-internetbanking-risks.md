# 인터넷뱅킹 시스템의 4단계 위험요소

## 한줄 요약
> 인터넷뱅킹 공격은 사용자/단말 → 네트워크 → 인증/거래 → 서버(금융기관) 4단계 공격표면(attack surface)을 따라 진행되며, 각 단계마다 대표 공격기법이 다르다.

## 1. 4단계 공격표면과 대표 위협

| 단계 | 대상 | 대표 위협 |
|---|---|---|
| 1. 사용자/단말 | PC, 스마트폰 | 피싱, 파밍, 스미싱, 메모리해킹, 키로거 |
| 2. 네트워크 | 전송 구간 | 스니핑, MITM, 세션 하이재킹 |
| 3. 인증/거래 | 로그인, 이체승인 | 인증우회, 거래정보 위변조 |
| 4. 서버(금융기관) | 은행 시스템 | 웹취약점 공격, APT, DDoS, 내부자 위협 |

## 2. 공격 흐름 도식화

```
[사용자/단말]                [네트워크]              [인증/거래]              [서버]
피싱/파밍/스미싱  ──▶  스니핑/MITM  ──▶  인증우회/거래위변조  ──▶  웹취약점/APT/DDoS/내부자
메모리해킹/키로거
```

## 3. 헷갈리기 쉬운 공격 쌍 비교

| 공격A | 공격B | 차이 |
|---|---|---|
| 피싱(Phishing) | 파밍(Pharming) | 피싱=가짜 링크로 유인, 파밍=DNS를 조작해 정상 주소를 입력해도 가짜 사이트로 이동 |
| 메모리 해킹 | 키로거 | 메모리해킹=실행 중인 프로세스 메모리 값(계좌번호 등)을 직접 조작/탈취, 키로거=키보드 입력값을 기록 |
| MITM | MITB(Man-in-the-Browser) | MITM=네트워크 경로상에서 가로챔, MITB=브라우저 내부(악성 확장/모듈)에서 직접 조작 |
| 파밍 | DNS 스푸핑 | 파밍은 결과(가짜사이트로 유도)를 가리키는 포괄적 용어, DNS스푸핑은 그 수단 중 하나(호스트파일 변조도 파밍의 다른 수단) |

## 암기 팁
- **4단계 순서**: "단말→네트워크→인증거래→서버" — 공격이 사용자에서 시작해 은행 서버까지 침투해가는 흐름으로 기억
- **"피싱은 링크 낚시, 파밍은 주소 자체를 바꿔치기"**
- **"메모리해킹은 눈에 안 보이는 값 조작, 키로거는 입력 감청"**

## 헷갈리는 포인트
- 파밍은 DNS 스푸핑뿐 아니라 **로컬 hosts 파일 변조**로도 이루어질 수 있음 — DNS스푸핑=파밍의 하위 수단 중 하나일 뿐
- MITM과 MITB를 혼동하기 쉬움 — MITM은 "중간 경로"에서, MITB는 "브라우저 안"에서 발생

## 관련 기출/문제
- 4단계 공격표면과 대표 위협 매칭
- 피싱 vs 파밍, 메모리해킹 vs 키로거 구분
- MITM vs MITB 차이
